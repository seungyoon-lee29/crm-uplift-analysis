# 의사결정 메모 — "CRM 푸시, 전체발송 vs ML 타겟팅"

> 수신자: 그로스팀장 · 작성: 데이터 분석가 · 근거: Hillstrom 6.4만 명 무작위배정 이메일 캠페인

## TL;DR
"그냥 다 보내면 되지"는 **이메일처럼 발송비·채널피로비가 낮은 경우엔 꽤 합리적입니다.** 이번엔 train/validation/test를 분리해 검증했더니, validation에서 좋아 보인 uplift 타겟팅 정책이 기본 이메일 가정의 test 평가에서는 전체발송보다 **$1,033 낮았습니다.** 다만 채널피로비가 **약 $0.17/통**을 넘으면 전체발송은 순손실로 돌아서므로, 푸시·SMS는 타겟팅뿐 아니라 무발송 옵션까지 포함해 holdout으로 검증해야 합니다.

## 1. 먼저 인정할 것 — 이메일은 평균적으로 먹힌다
무작위배정 비교에서 발송군의 증분은 visit **+57%**, conversion **+86%**, spend **+$0.60/명(+91%)**. 평균 효과가 분명히 양(+)이므로, "전체발송"을 게으른 선택이라고 *먼저* 매도하지 않습니다. (분석가가 결론을 정해놓고 데이터를 심으면 그게 더 위험합니다.)

## 2. 그런데 '평균'은 의사결정 단위가 아니다
의사결정 단위는 **한 통을 더 보낼 때의 한계 순이익**입니다.

순이익/명 = 증분구매 × AOV($117) × 마진(0.3) − 발송비($0.01) − 수신거부율 × LTV

uplift 모델은 랜덤보다 위입니다(Qini AUC validation 0.047, test 0.046). 하지만 신호가 약해서 분위별 증분의 95% CI가 넓고, validation에서 양(+)으로 보인 8개 분위만 test에 발송하는 정책은 **$448**로, 전체발송 **$1,481**보다 낮았습니다. 즉 "ML로 거르면 무조건 이긴다"가 아니라, **정책 선택과 최종 평가는 반드시 분리**해야 합니다.

## 3. 진짜 답은 '채널 피로비'에 달려 있다 (← 설득의 핵심)
| 채널피로비/통 | 전체발송 순이익 | 타겟발송 순이익 |
|---|---|---|
| $0.00 (피로 무시) | $2,121 | $960 |
| $0.05 (이메일) | $1,481 | $448 |
| ~$0.17 (전체발송 손익분기) | ~$0 | 변동 |
| $0.30 (푸시/SMS 가정) | **−$1,719** | −$454 |

- **채널피로비가 약 $0.17/통을 넘으면 전체발송은 순손실.** 푸시·카톡·SMS처럼 한 번 수신거부하면 *모든 미래 캠페인*을 잃는 채널이 여기 해당.
- 하지만 이번 uplift 정책도 test에서 항상 흑자는 아닙니다. 채널피로비가 큰 구간에서는 "전체발송 금지"가 먼저이고, 타겟팅은 더 보수적인 기준(CI 하한, 추가 홀드아웃)으로 검증해야 합니다.

## 4. 권고
1. **이메일**: 당장은 전체발송 유지가 더 설득력 있음. 모델 타겟팅은 기본 가정에서 test 검증을 통과하지 못함.
2. **푸시·SMS**: 전체발송은 위험. 다만 타겟팅도 자동 도입하지 말고, 보수적 cutoff와 무발송 옵션을 함께 A/B로 검증.
3. **검증**: 분위별 증분은 노이즈가 크다. **홀드아웃(무발송 대조군)을 상시 유지**해 증분을 지속 측정할 것.

## 5. 정직한 한계
- 수신거부율·LTV는 데이터에 없어 **가정**. → 그래서 단일 숫자가 아닌 *민감도*로 보고.
- uplift 신호 약함(test Qini 0.046) → 분위 증분 95% CI가 넓고 validation-selected 정책도 test에서 손해가 날 수 있음. 특정 분위를 "확정 sleeping-dog"으로 단정하지 않음.
