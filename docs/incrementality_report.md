# 증분 이익 리포트 — 전체발송 vs uplift 타겟발송 (top-k 정책)

발송 정책 = **단조 top-k%**(uplift 점수 상위 k%에 발송). k*는 **validation**에서 고르고 최종 성과는 **test**에서 평가하는 out-of-sample 규율.

AOV(구매자 평균 spend, validation 기준) = $117.10 · 가정: 마진 0.3, 발송비 $0.01, 채널피로비(수신거부×LTV) = $0.050/통

## 1. 헤드라인 — 기본 이메일 가정

- validation이 고른 발송 비율 **k\* = 100%** (상위 12800명).
- test 평가: 타겟발송 **$1490** vs 전체발송 **$1490** → 차이 **$+0(+0%)**.
- 전체 평균 증분구매 +0.0050/명 = 이메일은 평균적으로 먹힌다("다 보내"가 틀린 건 아님).
- → 검증된 top-k 타겟팅이 이메일에서도 전체발송 이상이다.

## 2. 정책 안정성 — 단조 top-k vs 비연속 분위 cherry-pick

같은 기본 가정·같은 validation/test에서 정책 선택 방식만 바꿔 비교.

| 정책 | 발송 규칙 | test 타겟발송 | vs 전체발송 |
|---|---|---|---|
| 비연속 분위 (구) | 분위 [2, 4, 5, 6, 7, 8, 9, 10] | $448 | $-1033 |
| **top-k% (신)** | 상위 100% | $1490 | $+0 |

- 비연속 분위는 validation 노이즈에 과적합(비단조 선택)되어 정책이 불안정. top-k는 단조·해석가능하며 out-of-sample에서 더 견고하다.

## 4. 채널 피로비 민감도 (← 진짜 '팀장 설득' 포인트)

피로비별로 validation에서 k*를 고르고 test 성과를 평가.

| 채널피로비/통 | k\* (발송%) | 전체발송 순이익 | 타겟발송 순이익 | 타겟팅 이득 |
|---|---|---|---|---|
| $0.00 | 100% | $2130 | $2130 | $0 |
| $0.05 | 100% | $1490 | $1490 | $0 |
| $0.10 | 95% | $850 | $817 | $-33 |
| $0.20 | 5% | $-430 | $119 | $549 |
| $0.30 | 5% | $-1710 | $55 | $1765 |
| $0.50 | 0% | $-4270 | $0 | $4270 |
| $0.70 | 0% | $-6830 | $0 | $6830 |
| $1.00 | 0% | $-10670 | $0 | $10670 |

**핵심1**: 기본 이메일 가정($0.05)에서 검증된 top-k 정책은 test에서 $+0(+0%) — 전체발송 이상. 약한 신호에선 타겟팅이 자동 승리가 아니다.
**핵심2**: 채널피로비가 **$0.17/통**을 넘으면 전체발송은 순손실. 이메일($0.05)은 안전권, 푸시·SMS면 위험 → 그 구간에서 top-k 타겟팅(또는 무발송)의 가치가 커진다.

→ 팀장 설득: "다 보내라"는 *싼 채널 + 무한 발송예산* 가정에서만 옳다. 피로비가 커지면 전체발송 손실 위험이 커지지만, uplift 정책도 validation/test로 검증해야 한다.
