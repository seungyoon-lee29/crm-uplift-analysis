# 정직한 한계

> 한계를 *아는 것*이 분석가의 일이다. 이 분석의 결론이 어떤 천장 위에 서 있는지 명시한다.

## L-1. 수신거부·LTV가 데이터에 없다 (가장 큰 천장)
Hillstrom의 결과는 `visit`/`conversion`/`spend`뿐. **수신거부(opt-out)·고객 LTV는 없다.** 따라서 "채널피로비"는 직접 측정이 아니라 **가정**(`config`)이다.
- 영향: "전체발송 vs 타겟발송"의 *손익분기 $0.15/통*은 가정에 의존.
- 대응: 단일 답이 아니라 **민감도**로 제시. 실서비스에선 수신거부 로그·LTV를 붙여 이 축을 실측해야 함.

## L-2. uplift 신호가 약하다 (Qini 0.030)
Hillstrom은 uplift가 본래 약한 데이터로 유명하다(문헌상 Qini 0.03~0.06). 모델은 랜덤보다 위지만 강하지 않다.
- 영향: **분위별 증분구매의 표준오차 ≈ ±0.004** vs 추정치 ±0.002 → 개별 분위의 부호(특히 중간 분위)는 노이즈와 구분 어려움.
- 대응: "분위 6,8 = 확정 sleeping-dog" 같은 단정 회피. 의사결정 *프레임*은 타당하되 *점추정*은 홀드아웃 재검증 전제.

## L-3. 단일 캠페인·단일 시점 (2008)
한 번의 이메일 캠페인 스냅샷. 시즌·업종·채널 일반화 불가.
- 대응: 결과는 *방향과 방법론*으로 해석. 절대 수치를 다른 맥락에 이식하지 않음.

## L-4. 발송 종류·빈도 미반영
이메일 종류(Mens/Womens)와 발송 빈도(피로 누적)는 이번 범위 밖. 실제 채널피로는 누적 발송수의 함수일 가능성이 큼.

## 실제 데이터가 있다면 (천장 제거 설계)
| 데이터를 얻으면 | 무엇이 풀리나 |
|---|---|
| 수신거부 로그 + 고객 LTV | 채널피로비를 *가정→실측*으로. 손익분기를 데이터로 확정 |
| 다회차 캠페인 이력 | 발송 빈도↔피로의 인과(이벤트 스터디), 최적 발송 간격 |
| 더 풍부한 행동 피처 | uplift 신호 강화 → 분위 노이즈 축소, 타겟팅 정밀도↑ |
